# 剪映草稿保险箱（Jianying Draft Backup）

一个小工具：每隔 3 分钟，把剪映专业版的草稿工程文件（`*.json`）复制一份快照到备份目录，防止剪映突然崩溃损坏正在剪的稿子。只备份轻量的工程元数据（json），不备份视频素材。自动保留最新 15 份快照，旧的自动删除。

> 本仓库仅存档工具脚本本身，不含任何实际草稿备份数据。

## 文件说明

- `backup.ps1` — 核心备份脚本：扫描草稿目录里的 json，复制近 20 分钟内改动过的文件到时间戳快照目录，并清理超过 15 份的旧快照。
- `loop.ps1` — 循环守护脚本：反复调用 `backup.ps1`，每次间隔 180 秒；在备份目录放一个名为 `STOP` 的文件即可停止。
- `make_shortcuts.py` — 一次性生成快捷方式（桌面 + 开机启动项），指向 `loop.ps1`。

## 原始路径（在本机时的配置）

- 草稿源目录：`E:\JianyingPro Drafts`
- 备份根目录：`D:\JianyingDraftBackup`

如需在别的机器使用，编辑 `backup.ps1` / `loop.ps1` 里的这两个路径即可。

## 用法

双击桌面快捷方式（或运行 `loop.ps1`）启动，后台静默每 3 分钟备份一次。放 `STOP` 文件到备份目录停止。
